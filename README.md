Проект содержит программный код для 7 спринта в Практикум
Описание файлов:
    Папка tests содержит следующие тесты:
    Задание:
        1. Создание курьера - файл test_create_courier.py
        2. Логин курьера - файл test_login_courier.py
        3. Создание заказа - файл test_create_order.py
        4. Список заказов - файл test_order_list.py
        Доп:
            1. Удалить курьера - файл test_delete_courier.py
            2. Принять заказ - файл test_accept_order.py
            3. Получить заказ по его номеру - файл test_get_order_by_number.py

    Папка functions содержит код используемых тестами функций:
        Файл base.py - функции генерации данных
        Файл courier.py - функции относящиеся к взаимодействиям с курьером
        Файл order.py - функции относящиеся к взаимодействиям с заказами

    Файл conftest.py - содержит фикстуры для тестов
    Файл constants.py - содержит ссылки на инструменты API
    Файл requirements.txt содержит используемые инструменты
    Папка allure_results содержит файлы Allure-отчета
